Descrição do Projeto: 

O projeto Laboratório Estatístico Interativo foi desenvolvido em Python e Streamlit.

A aplicação utiliza dados reais para realizar cálculos estatísticos, gráficos e simulações de forma interativa.

Link DataSet: https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews?resource=download

Instrução de instalação do Projeto: 

Para desenvolver o projeto, foi preciso realizar a instalação VS na máquina local, realizar todas as configurações necessárias e executar comendos das bibliotecas necessárias (pandas,numpy, streamlit e etc...).


Execução do projeto:

Para iniciar a aplicação, foi necessário executar o comando abaixo no terminal:

python -m streamlit run app.py

Após isso, era possível visualizar a aplicação  diretamente no navegador.
